The Petal Haus: guide for the whole group

This website uses HTML for content, CSS for appearance, and JavaScript for behavior . You can help without understanding every line: find the page or feature you want to change, make one small edit, save, and refresh.

1. Try the website before reading the code

  1. Choose a product: open Collections. Click its picture or Add to Cart. Choose a wrapper color or gift options, set the quantity, and save. The price updates with the quantity and Ferrero pack size. Potted flowers only need a quantity.
  2. Try gifts: Ferrero has flavors and piece counts; Pepero has flavors; candles have scents; customized letters accept a message. Greeting cards only need a quantity. The choices stay with the item.
  3. Try the shop controls: See More hides the other product sections. Show All restores them. The right arrow scrolls the product row to the right without rearranging the cards.
  4. Create a bouquet: open Customize. Select several flowers and set each flower’s stem quantity. Choose a wrapping style or a plain color. Selecting one mode clears the other mode. Choose several add-ons and configure each one. The summary lists all your selections.
  5. Open the cart: change a quantity, edit a shop item’s options, or delete an item. The total updates automatically.
  6. Check out: create a profile or sign in first, then enter your delivery details. Select credit card or GCash/Maya e-wallet. There is no cash-on-delivery option. Submit the order once.
  7. See the receipt: choose View receipt in the success message. It has a unique reference number, delivery details, selections, quantities, and total. Print it, save as PDF through your browser, or download an HTML receipt.
  8. Check review eligibility: open Feedback. The order is still Placed, so you cannot review it yet.
  9. Try contact and notifications: save a question on Contact Us and view it under Your inquiries. Open Notifications to see new item names, order updates, and unavailable cart items.

Use the same browser and site address for every step. For example, http://[::]:8000, http://localhost:8000, and http://127.0.0.1:8000 each have separate browser storage. Accounts and shopping data stay with the address where you created them.

The guest cart and orders follow the first sign-in. Signing out hides that profile’s orders and cart. Other profiles can see published reviews, but cannot open someone else’s receipt.

2. Which HTML file should you open?

The visible headings, paragraphs, forms, and photos are directly in these HTML files. There is no framework and no build step.

File What the visitor sees
index.html Home banner, reviews, store details, categories, and the slideshow showing one landscape photo at a time, every three seconds.
collections.html , occasions.html The shop’s product rows and category links.
customize.html Flower selection, wrapping choices, add-ons, and summary.
cart.html Chosen items, quantity edits, fixed prices, total, and checkout link.
checkout.html Delivery details and cashless payment selection.
receipt.html The saved order receipt and printing/download controls.
contact.html Map/phone links and inquiry form.
feedback.html Delivered-order review form and published reviews.
about.html , gallery.html Story, strengths, mission, vision, team roles, and pictures.
notifications.html Cart availability, new items, and order/inquiry updates.
Log-Sign/LoginPage.html, Log-Sign/SignUp.html The supplied account screens, connected to profiles.

The header and footer have readable copies in the storefront HTML files. To change their layout throughout the site, update each copy. Their map, phone, and email values come from settings.js .

3. What each JavaScript file does

File Plain-language purpose
settings.js Store contact details, available sample chocolate flavors and candle scents, and plain wrapping price.
products.js Product names, images, prices, flower costs, wrapping styles, and add-ons.
store.js Saves and checks carts, profiles, orders, delivery status, reviews, inquiries, stock, and notifications.
app.js Common menus, cart counters, success pop-ups, contact links, live reviews, animations, and home slideshow.
shop.js Product option forms, gift variants, calculated prices, See More, right scrolling, and search.
customize.js Multiple flowers, each stem quantity, exclusive wrapping modes, configured add-ons, and the summary.
pages.js The cart, checkout, receipt, inquiries, delivery-gated feedback, and notifications.
account.js Sign-in and sign-up forms, profile selection, and navigation.
styles.css and design-spec.css All main page colors, fonts, shapes, sizing, animation, and phone layout.

The scripts load in order using defer . After the browser finishes reading the HTML, startWebsite() prepares the saved data and connects the page features.

A function is a named set of instructions. An event is a click, typing, or another action. A const gives information a name, a let holds a value that can change, an if checks a condition, and a for repeats instructions.

4. Small edits your group can make

Change a sentence or heading

Open the relevant HTML file in a text editor. Search for words you recognize. Change the words between the tags and keep the tags. 

<h1>Make Every Moment</h1>
<p>A sentence your group can edit.</p>

h1 is a main heading, h2 a section heading, p a paragraph, a a link, and img a picture. The class connects an element to CSS. The id is its unique name. Keep class names, IDs, and data-* labels when changing only the words.

The story, mission, vision, and team roles in About Us are editable project copy. Replace the roles with your actual team names if needed.

Change a photo

<img src="assets/home/feat-pic-1.png"
     alt="A colorful flower shop display">

src is the picture path and alt describes it. Replace the path and description, or replace the image file while keeping its filename. The original reference images are preserved; the website uses the prepared copies in assets/ .

Change a product price

Open products.js and find the product record by name or ID: 

{
  id: "flower-1",
  name: "Tulip",
  price: 120,
  image: "assets/collections/flo-1.png",
  section: "flower",
  group: "collections"
}

Change price: 120 to price: 150 . Shop labels, search, and new cart selections use that value. Items already in a cart or receipt keep their saved price; remove and re-add an item to test a new price.

Some supplied customization or pop-up pictures still contain printed names/prices inside the bitmap. JavaScript cannot rewrite printed image text. Change the image too when you need to change that caption. The shop catalog uses separate live text below a cropped photo.

The HTML button’s data-add="flower-1" matches the product’s id . Do not change just one of those codes. A wrong code means the button cannot find its product.

Change colors, fonts, or sizes

Open styles.css . The main colors are near the top: 

--green: #577438;
--pink: #ef6e99;
--cream: #fffde9;
--yellow: #fff8b8;

var(--pink) means “use that saved pink color.” A rule such as .hero-greeting { font-size: 33.1rem; } changes the greeting size. The local @font-face rules load EB Garamond and Montserrat from the font folder.

At a desktop width of 1080 pixels, one rem in this design equals one pixel. Desktop layouts scale with the root size. Phone blocks beginning with @media replace selected sizes for smaller screens. The new content-page forms use ordinary px sizes for readability.

Useful CSS words: background sets a background, padding adds inside space, margin adds outside space, gap separates cards, and border-radius rounds corners. Later rules can replace earlier ones, including the latest cart specification block near the bottom.

Change the slideshow speed

In app.js , change GALLERY_SLIDE_DELAY = 3000 to 6000 for six seconds per photo. In CSS, transition: transform 0.6s ease controls how long the sliding movement takes.

The slideshow places pictures in a row, hides the pictures outside the viewport, and moves the row by one full picture width. It shows one photo at a time, cropped to fill the full landscape width. Arrows, dots, swipe, and pause/play are connected in initializeGallerySlideshow() .

Change contact details or gift choices

Edit settings.js . The phone and map address were copied from the reference. The references do not include an email, so that value is empty. Add an official address if your group provides one. The flavor/scent lists are configurable choices.

5. How the main features work

Feature The steps in the code
Shop selection Read the product ID → show option form → calculate unit price and quantity → save the configured item → show success.
Custom bouquet Remember every selected flower and stem count → remember one wrapping mode → remember each add-on → total the selections → save the entire bouquet as one cart item named “Customize Flowers”.
Checkout Require a signed-in profile → check delivery details and cashless method → check stock again → copy the cart into an order → generate a reference → clear the cart → show the saved receipt.
Review Check that the order belongs to the current profile → require Delivered status → prevent a second review → save and display the review.
Contact Check the required fields → save the inquiry → display it in Your inquiries.
Profile photo New accounts show initials. Open Profile → Add photo or Change photo → choose a JPG, PNG, WebP, or GIF up to 10 MB. The photo updates in the profile and header, and stays saved for that account in the same browser and website address. Remove photo restores the initials.
Logout Clear the active profile → return to the login screen. The previous profile’s saved cart and orders remain associated with that profile.

The customization calculation is each flower’s price × its stem count, plus one wrapping cost, plus each add-on’s configured price × its quantity . The starting example is six Sunflowers (600), wrapping (60), and a five-piece Ferrero add-on (250): PHP 910.

localStorage saves shopping data as text in this browser. JSON converts a list or record to and from saved text.

6. A simple group presentation

  • HTML member: show a heading, photo, form, and footer in an HTML file.
  • CSS member: show the color variables, EB Garamond/Montserrat fonts, cart styling, and a phone media rule.
  • JavaScript member: show product options, several flowers, checkout, receipt, and the review eligibility check.
  • Testing member: use the walkthrough above to check quantities, totals, empty search results, unavailable cart items, and sign-out.

A short explanation to practice: “HTML contains the pages, CSS follows our design, and JavaScript makes the shopping features work. The website saves configured items, records orders, generates receipts, and allows reviews only for delivered orders.”

Save and refresh after each edit. Keep brackets, commas, quotes, closing tags, IDs, and data labels. If a feature stops working, undo the last change and try a smaller edit. An image that disappears usually has a wrong path, filename, capitalization, or extension.
