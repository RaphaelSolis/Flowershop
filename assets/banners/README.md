Only the decorative banner photographs use these variants. Catalog photographs and product data retain their existing colors and files. Desktop banners display flowers with `object-fit: contain` in a separate grid column; their text column grows for longer headings. The Home banner and header/logo sizes retain their previous styles. Existing mobile banner typography and layout are preserved.
